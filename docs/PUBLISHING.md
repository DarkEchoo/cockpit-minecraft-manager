# Publishing checklist

1. Inspect each source file and confirm it contains no host addresses, credentials, private identifiers, user names, or organization data.
2. Do not add production `server.properties`, worlds, logs, backups, `/etc` configuration, or source archives.
3. Confirm this is a **development snapshot** and not a complete public installer.
4. Decide whether to add a license (e.g. MIT), and only do so if you own rights to all included code.
5. Create the repository on GitHub as **private** initially and inspect its contents.
6. Change repository visibility to public only after review and when ready to share the URL with CurseForge.

Suggested URL: `https://github.com/<your-github-username>/cockpit-minecraft-manager` — use the actual URL generated by GitHub.
